# MemoLite · WinUI 3

Windows 11용 로컬 텍스트 편집기입니다. C# / .NET 10 / WinUI 3로 새로 구현했습니다. 시스템 라이트·다크 테마와 Mica 배경, Windows 기본 탭·메뉴·파일 대화상자를 사용합니다.

프로그램 이름과 창 제어 버튼 사이의 제목 표시줄에 검색창과 `정리` 버튼을 배치했습니다. 검색창은 입력할 수 있고 나머지 제목 표시줄 영역은 창 드래그에 사용할 수 있습니다. 검색창과 정리 버튼은 디자인 확인용 UI이며 기능은 아직 연결되어 있지 않습니다. 왼쪽 사이드바는 기존 너비와 배경만 남겨 비워 두었습니다. 문서 작성과 파일 관리는 중앙 메모장의 메뉴와 단축키를 사용합니다.

## 실행

`run.bat`를 더블 클릭하거나 `artifacts/MemoLite/MemoLite.exe`를 실행합니다. 실행 파일은 .NET 및 WinUI 런타임을 포함합니다. Python은 필요하지 않습니다.

지원 환경은 **Windows 11 x64**입니다. 다른 PC로 전달할 때는 EXE와 함께 **artifacts/MemoLite 폴더 전체**를 복사해야 합니다.

파일을 실행 인수로 주면 문서 탭으로 엽니다.

```powershell
.\artifacts\MemoLite\MemoLite.exe "C:\notes\memo.txt"
```

## 기능과 단축키

| 기능 | 조작 |
| --- | --- |
| 새 파일 | Ctrl+N 또는 탭 옆 + |
| 파일 열기 (여러 파일 선택 가능) | Ctrl+O |
| 저장 | Ctrl+S |
| 다른 이름으로 저장 | Ctrl+Shift+S |
| 탭 닫기 | Ctrl+W 또는 탭의 × |
| 다음 / 이전 탭 | Ctrl+Tab / Ctrl+Shift+Tab |
| 탭 순서 변경 | 탭 드래그 |
| 탭 목록 가로 스크롤 | 탭 영역에서 휠 위: 왼쪽, 아래: 오른쪽 |
| 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y 또는 Ctrl+Shift+Z |
| 복사 / 붙여넣기 / 잘라내기 | Ctrl+C / Ctrl+V / Ctrl+X |
| 모두 선택 | Ctrl+A |
| 확대 / 축소 / 100% | Ctrl++ / Ctrl+- / Ctrl+0 |
| 마우스로 배율 변경 | 편집 영역에서 Ctrl+휠 |
| 메뉴 접근 | Alt를 누른 후 F / E / V |

보기 메뉴에서 자동 줄 바꿈과 상태 표시줄을 켜고 끌 수 있습니다. 상태 표시줄에는 커서 줄·열, 글자 수, 선택 글자 수, 줄바꿈 형식, 인코딩, 배율이 표시됩니다. 편집 영역을 우클릭하면 편집 메뉴가 열립니다.

본문의 마지막 줄 아래 빈 공간을 클릭하면 커서가 마지막 줄 끝으로 이동합니다. 기존 글자 위치 클릭과 드래그 선택은 일반 텍스트 편집기처럼 동작합니다.

새 문서는 숫자 없이 `제목 없음`으로 시작하며, 미저장 문서에 글을 쓰면 첫 줄이 자동으로 탭 제목이 됩니다. 첫 줄이 비어 있으면 다시 `제목 없음`으로 표시합니다. 저장된 문서는 파일명을 유지합니다. 같은 이름의 탭도 내용과 실행 취소 기록은 독립적이며, 앱을 다시 열어도 본문에서 제목을 복원합니다.

탭 너비는 134px로 고정합니다. 긴 제목은 `…`으로 줄여 표시하고, 마우스를 올리면 전체 제목 또는 파일 경로를 볼 수 있습니다. 수정한 탭은 닫기 버튼 자리에 테마에 맞는 회색 ●을 표시합니다. 탭 위에 마우스를 올리면 같은 자리에서 ×로 바뀌고, 벗어나면 다시 ●이 됩니다. 클릭 시 기존 저장 확인을 유지하며, 제목 길이나 수정 여부에 따라 탭 너비가 바뀌지 않습니다.

탭을 추가할 때 기본 등장·추가 전환 효과를 생략하고 바로 표시합니다. 드래그로 순서를 바꾸는 효과는 유지합니다. 새 편집기가 로드된 뒤 입력 포커스를 다시 요청합니다.

- **앱 창 닫기·Alt+F4·끝내기:** 저장 여부를 묻지 않고 열린 탭과 수정 내용을 임시 보관합니다. 다음 실행에서 탭 순서, 선택한 탭, 선택 영역, 배율·줄 바꿈·상태 표시줄 설정을 복원합니다.
- **탭의 ×·Ctrl+W:** 수정한 탭에만 저장·저장 안 함·취소를 묻습니다. ‘저장 안 함’으로 닫은 탭은 복원 기록에서도 제거합니다.
- **Ctrl+S·저장 메뉴:** 원본 파일을 실제로 갱신합니다. 앱 종료 시 임시 보관만으로 원본 파일을 덮어쓰지는 않습니다.

임시 보관은 `%LOCALAPPDATA%\MemoLite\sessions`에 창별로 저장됩니다. 편집 후 약 0.75초 동안 입력이 멈추면 기록을 갱신하며, 앱을 닫을 때 마지막 내용을 다시 기록합니다. 여러 창은 서로의 보관 파일을 덮어쓰지 않습니다. 다시 실행하면 사용 중이지 않은 가장 최근 창의 탭을 복원합니다. 실행 취소·다시 실행 이력은 현재 실행 중에만 유지됩니다.

복원할 내용과 선택 영역은 화면 스레드에서 수집하고, JSON 직렬화와 디스크 기록은 백그라운드에서 처리합니다. 기록 요청 순서와 종료 시 마지막 기록 완료 대기는 유지합니다. 클립보드 내용 조회는 편집 메뉴를 사용할 때만 수행합니다.

임시 보관에 실패하면 내용 보호를 위해 창을 닫지 않고 오류를 알립니다.

## 파일 저장

- 새 문서: UTF-8, Windows 줄바꿈(CRLF).
- 기존 문서: UTF-8(BOM 포함), UTF-16 LE/BE(BOM 포함), CP949를 읽고 원래 인코딩과 주된 줄바꿈 형식을 유지합니다.
- 혼합 줄바꿈은 저장할 때 가장 많이 사용된 형식으로 통일합니다.
- 기존 인코딩으로 표현할 수 없는 문자가 생기면 UTF-8 전환 여부를 확인합니다.
- 외부에서 변경·삭제된 파일은 덮어쓰기 전에 확인합니다.
- 다른 탭에서 열려 있는 파일로 저장하는 것은 막습니다.
- 먼저 같은 폴더의 임시 파일에 기록한 뒤 교체합니다. 쓰기 실패 시 원본과 수정 상태를 유지합니다.

## 개발 및 빌드

필요 도구: .NET 10 SDK, Windows SDK 10.0.26100 이상. Visual Studio에서는 WinUI 개발 도구를 설치하면 됩니다. NuGet 패키지 복원 시 인터넷 연결이 필요합니다.

`MemoLite.slnx`를 Visual Studio에서 열고 x64를 선택하거나, 다음 명령을 실행합니다.

```powershell
dotnet build src/MemoLite/MemoLite.csproj -c Debug -p:Platform=x64
.\build.bat
```

`build.bat`는 `artifacts/MemoLite`에 Release 실행 파일과 런타임을 생성합니다. 소스를 수정한 후에는 다시 빌드하고 실행하세요.

## 검증

```powershell
dotnet run --project tests/MemoLite.Core.Tests/MemoLite.Core.Tests.csproj -c Release
.\tests\Verify.ps1
```

핵심 로직 테스트는 40개이며, 인코딩·줄바꿈 왕복, 저장 실패 시 원본 보존, 세션 복원·창별 분리·손상 기록 보존 등을 검사합니다. `Verify.ps1`는 실제 WinUI 컨트롤 검증에 더해, 수정한 탭이 있는 앱을 종료한 뒤 별도 프로세스로 재실행하여 원본 파일 보존·미저장 내용·탭 순서·선택 영역·보기 설정 복원과 탭 제거 시 저장 확인을 검사합니다. 테스트용 세션은 사용자 세션과 분리됩니다. 또한 빈 폴더에 Release를 게시하고 실행 파일과 XAML 실행 리소스(`App.xbf`, `MainWindow.xbf`, `MemoLite.pri`) 포함 여부를 검사합니다. 결과는 `artifacts/verification`에 남습니다. 자동 검증 진입점은 Release 실행 파일에 포함되지 않습니다.

Debug 실행 파일은 `--profile-tabs "보고서 절대 경로"` 인수로 새 탭 성능을 측정할 수 있습니다. 사용자 세션과 분리한 임시 세션에서 +/Ctrl+N의 생성 경로와 장문 메모 복원 기록이 겹치는 상황을 검사하며, 구간별 시간과 화면 스레드 실행 횟수를 기록합니다. 이번 변경 전후 측정은 `artifacts/verification/tabs-before.txt`, `tabs-after.txt`에 있습니다. 이 값은 해당 PC의 합성 부하 측정이며 모든 간헐 지연을 재현한 결과는 아닙니다.

## 구성

- `src/MemoLite`: WinUI 화면, 문서 탭, 메뉴, 단축키, 파일 대화상자.
- `src/MemoLite.Core`: 텍스트 파일 입출력과 문서 상태.
- `tests/MemoLite.Core.Tests`: 외부 테스트 프레임워크 없이 실행하는 핵심 로직 검증.
- `tests/Verify.ps1`: 핵심 로직 및 실제 WinUI 컨트롤 검증 실행기.

UI용 Microsoft.WindowsAppSDK.WinUI 구성 요소만 참조하며 AI·ML 기능은 포함하지 않습니다.
